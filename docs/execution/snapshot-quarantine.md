# Selected malformed snapshot quarantine

This app-owned diagnostic tool handles only malformed historical scan snapshots. It refuses all parseable JSON, all trade/position/config files, paths outside `snapshots/*.json` or the verified legacy `state/snapshots/*.json` location, symlinks, oversized sources and decoder-limit failures. It does not repair financial records or infer a replacement value. Use canonical directory paths.

Preview with `PYTHONPATH=src python -m rshelper.recovery --root ROOT --snapshot snapshots/FILE.json`. Preview prints JSON with the selected relative path, size and SHA256, and creates no evidence or lock sidecar. Apply explicitly with the same arguments plus `--apply --expected-sha HASH --evidence-dir PRIVATE_DIRECTORY`. Evidence must be outside the active state root. A changed hash aborts before evidence creation.

Apply pins every source/evidence directory through no-follow directory handles and takes the persistent shared flock sidecar, captures and verifies a private 0600 ZIP in a unique 0700 evidence directory, then atomically moves the original relative to those pinned handles and verifies both its inode identity and hash. Directory replacement is detected; it cannot redirect the move to an external file or overwrite outside evidence. Both archive and raw original are retained; malformed evidence is not a trusted restore source. A failed move preserves the source and archive. A concurrent noncooperating write or failed post-move verification triggers exclusive restoration without overwriting a newer active file; the error reports active-path status and the retained original path. Cross-filesystem moves fail safely rather than copying and deleting. Keep lock sidecars. No broad or automatic cleanup is provided.

The exact historical two-byte malformed snapshot is recorded in the execution ledger. This code alone neither moves real files nor removes prior Git history. Strict deployment merge stays pending until selected copies have app-owned quarantine evidence and a fresh state preflight passes.

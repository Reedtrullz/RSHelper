**Goal:** Ship daemon monitor (v1.2), trade journal (v1.3), and multi-account profiles (v1.4) as self-contained modules with CLI + dashboard integration.

**Tech Stack:** Python 3.11+ stdlib only. `http.server` for dashboard. `subprocess` + `osascript` for macOS notifications. JSON state files with atomic writes (temp file + `os.replace`).

## Global Constraints

- Zero external dependencies — stdlib only
- All status/log messages → stderr. Stdout for clean JSON/CSV/HTML.
- State files use atomic writes (temp + os.replace)
- No abstractions without two concrete use cases
- Python 3.11+ (uses `tomllib`)
- Ponytail: simplest solution that works, deletion over addition
- Backward compatibility: all existing commands must work unchanged

## Phase 1: v1.2 — Daemon Monitor

**Depends on:** v1.1 signals module (complete). Independent of v1.3.

### Architecture decisions

- **Threading vs subprocess:** Use a simple `while True: sleep()` loop in the main thread. No threading needed — the monitor is the only thing running. `ThreadPoolExecutor` from `api.py` handles parallel timeseries fetches.
- **API failure handling:** Log to stderr, skip the cycle, continue. No retry/backoff in the monitor loop (the API client already has retry). Write `last_check_iso` only on successful cycles.
- **PID reuse:** Use `os.kill(pid, 0)` for liveness check. Not foolproof but sufficient for CLI use.
- **osascript:** `subprocess.run(["osascript", "-e", f'display notification ...'])`. Catch `FileNotFoundError` (non-macOS) and `CalledProcessError`. Never crash.

### Files

- **Create:** `src/rshelper/monitor.py`, `tests/test_monitor.py`
- **Modify:** `src/rshelper/cli.py` (subcommand), `src/rshelper/dashboard/handlers.py` (route), `src/rshelper/dashboard/templates.py` (status dot)

```python
"""Background monitor: polling loop with macOS notifications."""

import json
import os
import signal
import subprocess
import sys
import time
from datetime import datetime, timezone
from pathlib import Path

MONITOR_DIR = Path.home() / ".config" / "rshelper"
PID_PATH = MONITOR_DIR / "monitor.pid"
STATE_PATH = MONITOR_DIR / "monitor_state.json"


def notify(title: str, message: str) -> None:
    """Fire a macOS notification via osascript. No-op on failure/non-macOS."""
    try:
        subprocess.run(
            ["osascript", "-e",
             f'display notification "{message}" with title "{title}"'],
            capture_output=True, timeout=5,
        )
    except (FileNotFoundError, subprocess.CalledProcessError,
            subprocess.TimeoutExpired):
        pass  # non-macOS or osascript unavailable


def run_monitor(interval_sec: int = 120, no_notify: bool = False) -> None:
    """Main polling loop. Blocks until KeyboardInterrupt or SIGTERM."""
    MONITOR_DIR.mkdir(parents=True, exist_ok=True)

    pid = os.getpid()
    started = datetime.now(timezone.utc).isoformat()

    # Write PID atomically
    tmp = PID_PATH.with_suffix(".tmp")
    tmp.write_text(str(pid))
    os.replace(tmp, PID_PATH)

    # Initial state
    state = {"pid": pid, "started_iso": started,
             "last_check_iso": None, "profile": "default"}
    _write_state(state)

    print(f"[monitor] Started (PID {pid}, interval {interval_sec}s)", file=sys.stderr)

    try:
        while True:
            try:
                _poll_cycle(no_notify)
                state["last_check_iso"] = datetime.now(timezone.utc).isoformat()
                _write_state(state)
            except Exception as e:
                print(f"[monitor] Cycle error: {e}", file=sys.stderr)
            time.sleep(interval_sec)
    except KeyboardInterrupt:
        print("\n[monitor] Shutting down...", file=sys.stderr)
    finally:
        _cleanup()


def _poll_cycle(no_notify: bool) -> None:
    """One fetch-signals-watchlist-notify cycle."""
    from rshelper.cli import _fetch_bootstrap
    from rshelper.scanner import FlipScanner
    from rshelper.signals import detect_signals
    from rshelper import watchlist

    _mapping, _latest, vol_5m, items = _fetch_bootstrap()
    scanner = FlipScanner(direction="arbitrage")
    flips = scanner.scan(items)

    # Signals
    signals = detect_signals(flips, vol_5m)
    if signals and not no_notify:
        high = [s for s in signals if s.severity == "HIGH"]
        if high:
            notify("RSHelper Alert", f"{len(high)} high-severity signal(s)")
        elif len(signals) > 0:
            notify("RSHelper", f"{len(signals)} signal(s) detected")

    # Watchlist
    watched_ids = watchlist.get_watched_ids()
    if watched_ids:
        latest_prices = _latest
        wl = watchlist.load()
        for item_id_str, entry in wl["items"].items():
            price = latest_prices.get(item_id_str)
            if not price or not isinstance(price, dict):
                continue
            buy = int(price.get("high", 0) or 0)
            sell = int(price.get("low", 0) or 0)
            if buy <= 0 or sell <= 0:
                continue
            margin = sell - buy
            tax = min(5_000_000, max(1, int(sell * 0.02)))
            profit = margin - tax
            above = entry.get("alert_margin_above")
            below = entry.get("alert_margin_below")
            if (above is not None and profit > above) or \
               (below is not None and profit < below):
                if not no_notify:
                    notify("RSHelper Watchlist",
                           f"{entry['name']}: margin {profit:,} gp")


def stop_monitor() -> bool:
    """Kill running monitor by PID file. Returns True if a monitor was stopped."""
    if not PID_PATH.exists():
        return False
    try:
        pid = int(PID_PATH.read_text().strip())
    except (ValueError, OSError):
        PID_PATH.unlink(missing_ok=True)
        return False
    # Liveness check
    try:
        os.kill(pid, 0)
    except OSError:
        # Process doesn't exist — stale PID
        PID_PATH.unlink(missing_ok=True)
        return False
    try:
        os.kill(pid, signal.SIGTERM)
        PID_PATH.unlink(missing_ok=True)
        return True
    except OSError:
        PID_PATH.unlink(missing_ok=True)
        return False


def monitor_status() -> dict | None:
    """Return {running, pid, uptime_sec, last_check_iso} or None."""
    if not PID_PATH.exists() or not STATE_PATH.exists():
        return None
    try:
        pid = int(PID_PATH.read_text().strip())
    except (ValueError, OSError):
        return None
    # Liveness check
    try:
        os.kill(pid, 0)
    except OSError:
        return None
    try:
        state = json.loads(STATE_PATH.read_text())
    except (json.JSONDecodeError, OSError):
        return None
    started = state.get("started_iso")
    uptime = 0
    if started:
        try:
            started_dt = datetime.fromisoformat(started)
            uptime = (datetime.now(timezone.utc) - started_dt).total_seconds()
        except (ValueError, TypeError):
            pass
    return {
        "running": True, "pid": pid,
        "uptime_sec": int(uptime),
        "last_check_iso": state.get("last_check_iso"),
        "profile": state.get("profile", "default"),
    }


def _write_state(state: dict) -> None:
    tmp = STATE_PATH.with_suffix(".tmp")
    tmp.write_text(json.dumps(state))
    os.replace(tmp, STATE_PATH)


def _cleanup() -> None:
    PID_PATH.unlink(missing_ok=True)
    STATE_PATH.unlink(missing_ok=True)
```

## Phase 2: v1.3 — Trade Journal

**Depends on:** v1.1 signals module (for tax formula consistency). Independent of v1.2.

### Architecture decisions

- **Tax formula: per-item, not per-total.** The workplan spec says `max(1, int(sell_price * qty * 0.02))` which taxes the total sale. OSRS tax is per item, capped at 5M per item. Correct formula: `min(5_000_000, max(1, int(sell_price * 0.02))) * qty`.
- **Trade IDs:** Sequential integers starting from 1. Read max existing ID on load, increment.
- **State file:** `~/.config/rshelper/trades.json` — `{"trades": [...]}`. Atomic writes.

### Files

- **Create:** `src/rshelper/journal.py`, `tests/test_journal.py`

```python
"""Trade journal: log trades, compute P&L."""
import json
import os
from dataclasses import dataclass, field
from datetime import datetime, timezone
from pathlib import Path

TRADES_PATH = Path.home() / ".config" / "rshelper" / "trades.json"


@dataclass
class Trade:
    id: int
    item_id: int
    name: str
    qty: int
    buy_price: int
    sell_price: int
    tax_paid: int    # per-item tax * qty
    profit: int      # (sell - buy) * qty - tax_paid
    timestamp: str   # ISO 8601
    note: str = ""


@dataclass
class PnLSummary:
    total_profit: int = 0
    total_tax_paid: int = 0
    trade_count: int = 0
    winning_trades: int = 0
    losing_trades: int = 0
    win_rate: float = 0.0
    best_trade: Trade | None = None
    worst_trade: Trade | None = None
    active_gp_per_hour: float = 0.0
    items_traded: int = 0


def _ensure_dir() -> None:
    TRADES_PATH.parent.mkdir(parents=True, exist_ok=True)


def _load() -> list[dict]:
    _ensure_dir()
    try:
        if TRADES_PATH.exists():
            return json.loads(TRADES_PATH.read_text()).get("trades", [])
    except (json.JSONDecodeError, OSError):
        pass
    return []


def _save(trades: list[dict]) -> None:
    _ensure_dir()
    tmp = TRADES_PATH.with_suffix(".tmp")
    tmp.write_text(json.dumps({"trades": trades}))
    os.replace(tmp, TRADES_PATH)


def _next_id(trades: list[dict]) -> int:
    if not trades:
        return 1
    return max(t["id"] for t in trades) + 1


def log_trade(item_id: int, name: str, qty: int, buy_price: int,
              sell_price: int, note: str = "") -> Trade:
    """Log a completed trade. Returns the Trade object."""
    trades = _load()
    # Tax: per-item, capped at 5M, then * qty
    per_item_tax = min(5_000_000, max(1, int(sell_price * 0.02)))
    tax_paid = per_item_tax * qty
    profit = (sell_price - buy_price) * qty - tax_paid
    trade = {
        "id": _next_id(trades),
        "item_id": item_id, "name": name, "qty": qty,
        "buy_price": buy_price, "sell_price": sell_price,
        "tax_paid": tax_paid, "profit": profit,
        "timestamp": datetime.now(timezone.utc).isoformat(),
        "note": note,
    }
    trades.append(trade)
    _save(trades)
    return Trade(**trade)


def delete_trade(trade_id: int) -> bool:
    """Delete a trade by ID. Returns True if it existed."""
    trades = _load()
    for i, t in enumerate(trades):
        if t["id"] == trade_id:
            trades.pop(i)
            _save(trades)
            return True
    return False


def list_trades(item_name: str = "", since: str = "", top: int = 0) -> list[Trade]:
    """List trades, optionally filtered by item name or date."""
    trades = _load()
    result = [Trade(**t) for t in trades]
    if item_name:
        q = item_name.lower()
        result = [t for t in result if q in t.name.lower()]
    if since:
        result = [t for t in result if t.timestamp >= since]
    result.sort(key=lambda t: t.timestamp, reverse=True)
    if top > 0:
        result = result[:top]
    return result


def compute_pnl(since: str = "") -> PnLSummary:
    """Compute profit and loss summary."""
    trades = list_trades(since=since) if since else list_trades()
    if not trades:
        return PnLSummary()

    total_profit = sum(t.profit for t in trades)
    total_tax = sum(t.tax_paid for t in trades)
    winners = [t for t in trades if t.profit > 0]
    losers = [t for t in trades if t.profit < 0]
    best = max(trades, key=lambda t: t.profit)
    worst = min(trades, key=lambda t: t.profit)

    # Active gp/hr: profit / hours between first and last trade
    timestamps = sorted(t.timestamp for t in trades)
    if len(timestamps) >= 2:
        try:
            first = datetime.fromisoformat(timestamps[0])
            last = datetime.fromisoformat(timestamps[-1])
            hours = (last - first).total_seconds() / 3600
            active_gp_per_hour = total_profit / hours if hours > 0 else 0
        except (ValueError, TypeError):
            active_gp_per_hour = 0
    else:
        active_gp_per_hour = 0

    unique_items = len(set(t.item_id for t in trades))

    return PnLSummary(
        total_profit=total_profit, total_tax_paid=total_tax,
        trade_count=len(trades),
        winning_trades=len(winners), losing_trades=len(losers),
        win_rate=len(winners) / len(trades) * 100 if trades else 0,
        best_trade=best, worst_trade=worst,
        active_gp_per_hour=round(active_gp_per_hour),
        items_traded=unique_items,
    )
```

## Phase 3: v1.4 — Multi-Account Profiles

**Depends on:** v1.2 (monitor.py state files) and v1.3 (journal.py trades path). Both must be complete before this phase.

### Architecture decisions

- **Active profile resolution:** Read `~/.config/rshelper/active_profile`. Empty/missing → `"default"`.
- **Default profile:** Uses legacy paths directly (no `profiles/default/` subdirectory). Backward compatible.
- **Named profiles:** Config/cache/watchlist/trades/snapshots/monitor all under `profiles/<name>/`.
- **`--profile` override:** Set on the top-level argparse. Overrides the active_profile file for that one command. Does NOT change the active_profile file.
- **No concurrent access guard:** The `active_profile` file has no locking. Documented limitation (ponytail: per-account locks if throughput matters).

### Path resolution pattern

```python
# profile.py
def resolve_path(base: Path, profile: str | None = None) -> Path:
    """Resolve a config/cache path for the given profile."""
    if profile is None:
        profile = get_active_profile()
    if profile == "default":
        return base
    return base / "profiles" / profile
```

Where `get_active_profile()` reads the `active_profile` file.

## Known Risks

1. **PID reuse (v1.2):** `os.kill(pid, 0)` isn't foolproof — a new process could reuse a stale PID. Mitigated by the state file timestamp check.
2. **Tax formula difference (v1.3):** The workplan spec says per-total tax. We use per-item tax (correct OSRS behavior). This affects test expectations.
3. **osascript is macOS-only (v1.2):** `notify()` is a no-op on other platforms. Acceptable — the workplan explicitly targets macOS.
4. **No concurrent profile access (v1.4):** File locking on `active_profile` is not implemented. Concurrent CLI calls could race on the active profile read/write.
5. **Profile isolation of signal cooldowns (v1.4):** `signals.py` uses `~/.config/rshelper/signal_cooldowns.json` directly and must be refactored.
